# COVID Economic Analysis

## Overview

This project explores economic data related to the COVID period. The aim was to identify changes in economic indicators and use visualisations to understand trends over time.

## Methods

The analysis included:
- Data cleaning
- Exploratory data analysis
- Visualisation of trends
- Comparison of economic indicators over time

## Files

- `covid_economic_analysis.ipynb` — notebook containing the analysis

## Skills Shown

- Data cleaning
- Exploratory data analysis
- Data visualisation
- Interpreting economic trends
